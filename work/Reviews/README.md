# Retained review evidence

These screenshots are archived review artifacts, not runtime textures:

- `ExplorationAudits/SolitudeAudit`: exploration and locker audit captures.
- `OpeningSlice`: opening-room and locker art review captures.

Original `.meta` sidecars are retained alongside the archived files/folders so a
deliberate restoration into Unity can preserve their identities. Unity does not
import this directory. Put disposable captures and archives in the ignored
`work/Temporary` directory instead.
